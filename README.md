# Vista 360 del Cliente — FADESA

Mockups navegables de la ficha **Vista 360 del cliente** para Bitrix24. Cuatro propuestas de interfaz, con datos de muestra, pensadas para revisión con el cliente.

## Entregables

| Archivo | Propuesta |
|---|---|
| [`propuesta-b.html`](propuesta-b.html) | **Estilo industrial** — panel fijo de "la llamada" + pestañas Comercial / Cartera / Planta. |
| [`propuesta-c.html`](propuesta-c.html) | **Dashboard SaaS** — hero índigo, métricas pastel, donuts y barras por mes. |
| [`propuesta-d.html`](propuesta-d.html) | **Limpio, por pestañas** — canvas blanco, pestañas Resumen/Comercial/Cartera/Relación/Planta y tira de KPIs fija. |
| [`buscador.html`](buscador.html) | **Buscador completo** — índice de clientes con búsqueda en vivo y columnas analíticas. |
| [`buscador-simple.html`](buscador-simple.html) | **Buscador simple** — encabezado limpio conservando la tabla. |

`index.html` es la portada que enlaza a las cuatro.
